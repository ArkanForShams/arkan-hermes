## Current decision gate

No production implementation should begin until the discovery baseline, integration constraints, data ownership, compliance applicability, and MVP acceptance criteria are approved.

## Working interpretation

Quicklead requires one enterprise platform with two experience layers:

- B2C mobile customer application for Saudi/GCC individual vehicle owners.
- B2B fleet portal for corporate, leasing, and fleet-management customers.
- API/integration layer protecting the existing Quicklead operational system of record.
- Shared identity, notification, payment, analytics, audit, and governance capabilities.

## Important source ambiguity

The supplied visual contains both `QUICKLEAD` and `AUTO LEAD` branding. The product/legal brand, tenant model, and whether Auto Lead is a parent or alternate brand must be confirmed before final UI or domain decisions.
