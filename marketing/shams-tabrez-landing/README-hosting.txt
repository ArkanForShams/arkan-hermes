# Shams Tabrez — Personal Landing Page

## BEFORE HOSTING — 2 minutes
Open index.html in any text editor and replace the two placeholder links (marked with TODO comments):
1. "Connect on LinkedIn"  -> your LinkedIn profile URL (appears in hero and contact sections)
2. "Write to me"          -> mailto:you@example.com with your email

Search for "TODO" and you will find both spots (4 occurrences).

## HOSTING OPTIONS (pick one)
1. GitHub Pages (free): create repo, upload index.html, Settings > Pages > deploy from main.
2. Netlify Drop (free): go to app.netlify.com/drop and drag the file in. Done.
3. Any web host: upload index.html to the public root (public_html / www).

No build step. No dependencies. Everything (including the hero artwork) is embedded in the single file.

## FILES
- index.html — the complete landing page (self-contained)
- shams-tabrez-design-system.css — design tokens for future pages (already inlined in index.html)
- shams-tabrez-brand-bible.md — brand strategy document
- assets/pillars-hero.jpg — standalone hero artwork
