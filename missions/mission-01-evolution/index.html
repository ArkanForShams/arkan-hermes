Seven layers deep.

Over two days, the seven-layer Memory OS went live. From that point on, ARKAN stopped forgetting — and started accumulating.

LAYER 1 · WORKSPACEThe desk

Workspace files injected into every turn — the desk is always set.

LAYER 2 · SESSIONThe conversation

Full-text session memory — nothing said in a session is lost to it.

LAYER 3 · FACTSThe ledger

Structured facts with Bayesian trust scoring — born at 0.5, moving only through feedback.

LAYER 4 · FABRICThe fabric

Cross-session memory with live [fabric] injections — lessons carry across sessions.

LAYER 5 · QDRANTThe vault

Vector recall — hybrid dense + BM25. Scored 1.00 on its first test.

LAYER 6 · WIKIThe book

A self-curating wiki — knowledge that maintains itself.

LAYER 7 · GROUND TRUTHThe law

Written into SOUL.md itself: injected memory is authoritative — use it, never re-discover it.
